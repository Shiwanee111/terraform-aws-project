# terraform-aws-project

AWS EC2 infrastructure provisioned automatically using Terraform IaC.

## 🛠️ Tech Stack
- **Terraform** — Infrastructure as Code
- **AWS EC2** — Cloud Server
- **AWS Security Group** — Network Security
- **IAM** — Access Management

## 🔄 What Terraform Created
- EC2 Instance (t3.micro)
- Security Group (Port 22 + 3000)
- All in ap-south-1 region

## ▶️ How to Run
terraform init
terraform plan
terraform apply
terraform destroy
